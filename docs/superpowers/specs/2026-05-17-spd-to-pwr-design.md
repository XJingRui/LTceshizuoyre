# SpdToPwr：车速到能耗与温度预测 — 设计方案

日期：2026-05-17

## 1. 项目概述

基于岚图电动汽车行车数据，构建一个一键运行的 Python 脚本流程，完成数据清洗、统计分析、充电/行程分析和 LSTM 时序预测。最终目标：输入行车传感器序列，预测总驱动功率和电芯/电机温度。

## 2. 文件架构

```
SpdToPwr/
├── config.py           # 所有路径、超参数、可调配开关
├── data_utils.py       # 步骤 1-3: 读取 → 清洗 → 插值补齐
├── analysis.py         # 步骤 4-6: 统计描述 → 可视化 → 充电分析 → 行程分析
├── model.py            # BiLSTM + Attention 模型定义（PyTorch）
├── train.py            # 步骤 7-8: 构造样本 → 训练 → 评估 → 画图
├── run_all.py          # 总入口: python run_all.py 一键跑通
│
├── data/               # 预处理后的 parquet 数据（三辆车）
├── models/             # 训练好的 .pth + scaler
├── analysis_results/   # 统计图表、相关性热力图
└── training_results/   # loss 曲线、预测 vs 真实对比图、注意力热力图
```

### 各模块职责

| 文件 | 做什么 | 输入 | 输出 |
|------|--------|------|------|
| `config.py` | 集中管理所有可调参数 | 无 | 被其他模块 import |
| `data_utils.py` | 加载 CSV、找表头、清洗类型、线性插值 | 原始 CSV | 干净 DataFrame → `data_cleaned.parquet` |
| `analysis.py` | 描述统计 + 图表 + 充电/行程分析 | 干净 DataFrame | PNG 图表到 `analysis_results/` |
| `model.py` | 定义 BiLSTM + Bahdanau Attention 网络结构 | 无 | `BiLSTMAttentionPredictor` 类 |
| `train.py` | 构造时序样本、训练、评估、画图 | 干净 DataFrame + 模型 | `.pth` 模型 + 训练曲线到 `training_results/` |
| `run_all.py` | 按顺序调用上述模块 | 无 | 全流程跑完，打印摘要 |

## 3. 统计分析（6 个维度）

### 3.1 基础描述统计
每列均值、中位数、标准差、最大/最小值、四分位数、缺失率。关注量纲差异和缺失严重程度。

### 3.2 分布形态分析
直方图 + KDE + 箱线图，逐列看分布形状。关注偏度和离群点（IQR 法）。

### 3.3 相关性矩阵
Pearson + Spearman 热力图。关注车速-功率、温度-空调功率、加速踏板-功率的相关强度。

### 3.4 时间序列切片
关键变量（车速、功率、SOC、温度）随时间动态变化。ACF/PACF 判断时序依赖窗口，滚动均值和标准差评估平稳性。

### 3.5 工况分组对比
按驾驶模式、充电状态、能量回收模式、环境温度区间分组，对比功率分布和 SOC 消耗速率。

### 3.6 效率与能耗指标
衍生指标：瞬时能耗率（kWh/km）、SOC 变化率、电机效率、PTC/空调能耗占比。

## 4. 充电分析（7 个角度）

1. **充电曲线特征**：SOC-功率/电压/电流曲线，识别恒流段/恒压段拐点
2. **充电效率分析**：充电效率 = 电池吸收功率 / 输入功率，分 SOC 区间对比，低温效率衰减
3. **充电温升分析**：电芯温度上升曲线，温升速率（℃/1% SOC），PTC 加热与温升关系
4. **充电时长与充电量**：每次充电持续时间、SOC 增量、净充电量（kWh 估算）、峰值功率
5. **SOC 区间偏好**：起始/结束 SOC 分布，窗口宽度，满充满放 vs 浅充浅放模式
6. **充电段识别与分段**：按充电状态字段自动切分独立充电事件，快充/慢充分类
7. **充电安全性指标**：最高电芯温度阈值检查，温差检查，异常点标记

## 5. 行程分析（8 个角度）

1. **行程基础画像**：时长、距离（车速积分）、平均/最高车速、行程数统计
2. **行程能耗分析**：总能耗、能耗率（kWh/100km）、各行程排名、能耗 vs 平均车速散点图
3. **驾驶工况分类**：车速判据（城市 <30 / 郊区 30-60 / 高速 >60 km/h），各工况占比与能耗率对比
4. **加速与制动行为**：加/减速度分布，急加速/急减速次数，踏板开度分布
5. **能量回收分析**：回收总量、回收占比、不同模式回收效率、回收功率峰值
6. **温度演化**：电机/电芯温度变化曲线，温升与环境温度关系，高速稳态温度
7. **行程间对比与聚类**：能耗率分布直方图，按驾驶模式/环境温度着色，异常行程识别
8. **空调与附件能耗占比**：空调/PTC 功率随时间变化，占比分析，春秋 vs 冬夏对比

## 6. 能耗预测模型：BiLSTM + Attention

### 6.1 输入输出

- **输入特征 X（9 维）**：加速踏板开度、制动踏板状态、车速、驾驶模式、能量回收模式、空调EDC实际功率、座舱PTC实际功率、环境温度、乘员舱实际温度
- **预测目标 Y**：总驱动功率 = 前电机机械功率 + 后电机机械功率（kW），单标量

### 6.2 滑动窗口

```
seq_len = 20（用过去 20 步预测下一步）

样本1: X = [t1 .. t20]  →  y = 总功率[t21]
样本2: X = [t2 .. t21]  →  y = 总功率[t22]
...
```

关键参数：`seq_len=20`，`pred_horizon=1`（后续可扩展多步）。数据按时间顺序排列，**不 shuffle**。

### 6.3 模型结构

```
输入 (batch, 20, 9)
    → 线性投影+ReLU (9→128)
    → BiLSTM (2层, hidden=128, bidirectional)
       层间 BatchNorm
       输出 (batch, 20, 256)
    → Bahdanau Attention
       打分: score = vᵀ·tanh(W·h + b)
       权重: softmax(score)
       输出: context (batch, 256)
    → Dropout (0.3)
    → FC: 256 → 128 → 64 → 1
    → 预测 ŷ (batch, 1)
```

选用 Bahdanau（加法注意力）而非 Scaled Dot-Product 的理由：数据量有限、序列较短，加法注意力有可学习参数更适配小数据场景。

### 6.4 训练配置

| 配置项 | 值 |
|--------|-----|
| Loss | MSE |
| 优化器 | AdamW（lr=1e-3, weight_decay=1e-4） |
| 梯度裁剪 | max_norm=1.0 |
| 学习率调度 | ReduceLROnPlateau（patience=8, factor=0.5, min_lr=1e-6, cooldown=3） |
| 早停 | patience=20, min_delta=1e-4, 恢复最佳模型 |
| batch_size | 64 |
| max_epochs | 150 |
| 标准化 | StandardScaler（训练集 fit，验证/测试集 transform） |

### 6.5 数据集划分

按时序按行程切分，不随机打乱：

- 前 70% 行程 → 训练集
- 中间 15% 行程 → 验证集
- 最后 15% 行程 → 测试集

### 6.6 评估指标

| 指标 | 说明 |
|------|------|
| RMSE | 主指标，单位 kW |
| MAE | 平均绝对误差 |
| R² | 拟合优度 |
| MAPE | 百分比误差 |

### 6.7 可视化输出（6 张图）

1. **Loss 曲线**：train_loss + val_loss × epoch，标注 lr 衰减点和最佳 epoch
2. **预测 vs 真实散点图**：对角线参考线，密度着色
3. **时序对比**：测试集随机 500 步，真实值（蓝）vs 预测值（红）
4. **残差分析**：残差分布直方图 + KDE，残差 vs 预测值散点图
5. **注意力权重热力图**：X=时间步，Y=样本，颜色深浅=注意力权重
6. **特征重要性**：排列重要性柱状图（逐个 shuffle 特征看 RMSE 上升）

输出目录：`training_results/power/`

## 7. 温度预测模型

### 7.1 与能耗预测的差异

| | 能耗预测 | 温度预测 |
|------|----------|----------|
| 输入 X | 9 维 | 7 维（电池包总电流、前/后电机电流、车速、环境温度、电池PTC功率、空调EDC功率） |
| 输出 Y | 单标量（总驱动功率） | 4 维（最高电芯温度、最低电芯温度、前电机温度、后电机温度） |
| seq_len | 20 | 40（温度变化更慢） |
| 输出目录 | `training_results/power/` | `training_results/temp/` |

### 7.2 模型结构

与能耗预测同结构（BiLSTM + Bahdanau Attention），仅 FC 输出层改为 4 维。Loss = 4 个目标的 MSE 等权重求和（Loss_total = MSE₁+MSE₂+MSE₃+MSE₄）。

## 8. 运行流程

```
python run_all.py
    │
    ├─ Step 1-3: data_utils.py → data_cleaned.parquet
    ├─ Step 4-6: analysis.py → analysis_results/*.png
    ├─ Step 7:   train.py (能耗预测) → training_results/power/*
    └─ Step 8:   train.py (温度预测) → training_results/temp/*
```

运行完成后打印摘要：数据行数/字段数/缺失率、充电次数/行程数、能耗模型和温度模型的 Test RMSE/R²、所有输出文件路径。
